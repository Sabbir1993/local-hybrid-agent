# sandbox-requirements.txt
# Dependencies for the Isolated Code Runner (run_sandbox_python)
#
# These packages must be installed inside the execution sandbox environment:
#   - WSL2 Guest (e.g., Ubuntu 24.04):
#       wsl -d Ubuntu-24.04 -- sudo apt update && sudo apt install -y python3-pip
#       wsl -d Ubuntu-24.04 -- pip install -r sandbox-requirements.txt --break-system-packages
#   - Linux / macOS host running the runner locally:
#       pip install -r sandbox-requirements.txt
#   - Dedicated runner VM (Alpine): run tools/runner/setup.sh - it installs tools/runner/requirements.txt
#
# Keep identical to tools/runner/requirements.txt (the Alpine VM runner installs that copy).
# The execution sandbox is airgapped (network is disabled during execution).
# All dependencies must be pre-installed before running jobs.
