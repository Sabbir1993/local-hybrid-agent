🌐 Network Access

          
Admin only — internal IP ranges that web_fetch may reach

        

        

          

            By default web_fetch refuses any address that is not publicly routable (SSRF protection).
            Add a CIDR here to let it reach a trusted internal service such as an intranet host on this server.
            Cloud metadata endpoints (169.254.169.254), localhost and this app's own ports can
            never be allowed. IPv4 prefixes are /0-/32 — a typical LAN
            is /24 (e.g. 192.168.193.0/24); /55 is invalid and prevents the
            whole list from saving. Every change is written to the audit log.
          

          
          
          

            
            
          

        

      


      
      

        

          
⚠️ Danger Zone

          
Irreversible: permanently wipes chats, sessions, projects, and indexed memory

        

        

          

            Permanently deletes every user's chat history, sessions, projects, plan
            items, and indexed chat/workspace memory. Files on disk under the workspace root,
            the organizational knowledge base, user accounts, and audit log are not affected.
            This cannot be undone.
