📖 Connect an Agent 

    

      
1

      

        Load a model
        
Pick a model from the dropdown and press ▶ Load. The server must show Loaded before any agent can connect.

      

    

    

      
2

      

        Point your agent at the base URL
        

          http://localhost:8000/v1
          
        

        
OpenAI-compatible. Works with any client that accepts a custom base URL — Continue, Cline, LibreChat, Open WebUI, LangChain, the OpenAI SDKs, etc.

      

    

    

      
3

      

        Use this exact Model ID
        

          —
          
        

        
This is the currently loaded model's file path. Most agents require it in the model field. No API key needed — put any placeholder like none if the client insists on one.

      

    

    

      
4

      

        Example: OpenAI Python SDK
        
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="none",
)
resp = client.chat.completions.create(
    model="<paste the Model ID from step 3>",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(resp.choices[0].message.content)

      

    

    

      
5

      

        Verify it's working
        
Open 📡 Monitor in this UI — you'll see your agent's calls appear in real time (endpoint, tokens, prompt/gen speed). All traffic is also recorded in 📊 Report.

      

    

    

      
6

      

        Extend the agent with capabilities
        
All capabilities are managed in Settings → 🧩 Capabilities (toggles persist to config/app.json). The agent gets the tools automatically after a restart.


        
🌐 Web browsing — built in. The agent can web_search (DuckDuckGo, keyless) and web_fetch any URL. Optional: set capabilities.web_search_api_key in config/app.json if you hit search rate limits.


        
🎯 Skills — create a folder with a SKILL.md:

        
skills/my-skill/SKILL.md
---
name: my-skill
description: One line shown to the agent.
triggers: keyword1, keyword2
---
Full instructions the agent reads via read_skill.


        
🔌 MCP servers — add to config/app.json, restart:

        
"capabilities": { "mcp_servers": {
  "filesystem": {
    "transport": "stdio",
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-filesystem", "E:\\AI\\workspace"]
  },
  "remote": { "transport": "http", "url": "http://127.0.0.1:9000/mcp" }
}}

        
Tools appear as mcp__<server>__<tool>. A working echo test server is preconfigured.


        
🧩 Plugins — Python modules in plugins/<name>/plugin.py:

        
def register(api):
    api.add_system_prompt("Always do X.")
    api.add_tool("my_tool", my_fn, "Description shown to the agent.",
                 {"type": "object", "properties": {}})
    api.on_event("after_tool", lambda name, args, result: None)


        
See everything registered: Settings → 🧩 Capabilities shows every tool from every source with status and toggles — or open http://localhost:8000/control/capabilities in a browser for the full JSON listing (web tools, skills, MCP servers + their tools, plugins, total count).

      

    

    

      
7

      

        Fast CPU Router: Switch between Needle-2 and Laya (0 VRAM)
        
The agent uses a CPU router for instant sub-step tool routing without touching GPU VRAM. You can switch engines anytime in config/app.json:

        
"router": {
  "enabled": true,
  "confidence_threshold": 0.75,
  "engine": "cactus_needle",  // change to "laya" to switch
  "executor_grammar": true,
  "laya": {
    "checkpoint": "convaiinnovations/laya",
    "subfolder": null,
    "device": "cpu",
    "preload": false
  }
}

        
🌵 Cactus Needle-2 ("engine": "cactus_needle"): 45M compact model (~14MB binary). Grammar-constrained tool and argument extraction. Requires pip install needle.

        
⚡ Convai Laya ("engine": "laya"): 421M ModernBERT System 1 decision engine on CPU (device="cpu"). High-accuracy semantic routing and calibrated probabilities. Requires pip install laya.

        
Both engines operate completely on CPU (0 MB VRAM), preserving 100% of Arc A770 GPU memory for your primary models.
